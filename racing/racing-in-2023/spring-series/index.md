Racing will start for Keelboats and Dinghies from March through to 23rd April, apart from Easter weekend.

Dinghy Racing will be on Sundays from 12th March, with the first warning signal at 1445.

Keelboat racing will be on Sundays from 19th March, with the first warning signal at 1420.

For 2023 the club is moving to use the RYA YTC handicap scheme. This requires an application for a certificate to be completed. This requires a few simple measurements; manufacturers' measurements will be accepted. This application is done online at [the RYA YTC website](https://ytc.rorcrating.com/). It can take up to a week for your certificate to arrive so please do this in advance of the start of racing.
