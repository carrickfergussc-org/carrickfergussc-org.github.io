# Amendment to Notice of Race

### Notice of Race 6.3; amend as follows:

6.3 The scheduled time of the warning signal for the first race each day is 1410 for Keelboat classes and 1425 for Dinghy classes.

# Amendments to Dinghy Sailing Instructions

### Sailing Instruction 5; add 5.2 as follows:

5.2 When flag AP is displayed ashore, ‘1 minute’ is replaced with ‘not less than 15 minutes’ in Race Signals AP. 

### Sailing Instruction 6.3; amend as follows:

6.3 The scheduled time of the warning signal for the first race each day is 1425.

### Sailing Instruction 11, insert 11.1 as follows and renumber remaining in this section:

11.1 Races will be started using RRS 26 with the warning signal made 3 minutes before the starting signal, and the preparatory signal made 2 minutes before the starting signal. This changes RRS 26.
