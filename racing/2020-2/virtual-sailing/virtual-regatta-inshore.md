The Virtual Regatta Inshore Game can be accessed at this link [https://www.virtualregatta.com/en/inshore-game/](https://www.virtualregatta.com/en/inshore-game/)

The racing will be run using a custom race with the access code being provided in the Race Management WhatsApp group a few minutes before the start sequence.

The RYA website has some good information on getting started [https://www.rya.org.uk/Pages/virtual-regatta.aspx](https://www.rya.org.uk/Pages/virtual-regatta.aspx)
