Rescheduled to Saturday 29th August due to weather.

Saturday 22nd August should have been the CSC Regatta. Whilst the circumstances make it impossible to have a ‘normal’ regatta day, we propose to run a ‘Members Regatta Day’ with some organised racing and outdoor social activity afterwards. Hopefully everyone will be able to enjoy some fun racing and a bit of socially distanced craic afterwards.

The proposed format for the day us;<br>10.30 Junior Fun Race<br>13.00 Keelboat  Race<br>13.05 Dinghy Race

If you intend to participate please register via the link below.
